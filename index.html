Exam Builder

Paste a JSON config, load it, and take the exam. Your last config is remembered in this browser.

Config format 
{
  "title": "string (required)",
  "description": "string",
  "timeLimitMinutes": 10,        // optional
  "passingScore": 70,            // percent, optional
  "shuffleQuestions": false,     // optional
  "shuffleOptions": false,       // optional
  "showAnswersAtEnd": true,      // optional
  "passages": [                  // optional reading texts
    {"id": "p1", "title": "optional", "text": "Use \\n for line breaks"}
  ],
  "questions": [
    {
      "question": "string",
      "options": ["A", "B", "C"],
      "answer": 1,               // index, or [0, 2] for multi-select
      "passage": "p1",           // optional: id from "passages"
      "explanation": "optional"
    }
  ]
}
